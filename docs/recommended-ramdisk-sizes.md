# dacapo

We recommend the following sizes for the RAM disk:

| DaCapo Datasize | Safe RAM Disk Size |
|---|---|
| Small | 512 MB |
| Default | 2 GB |
| Large | 4 GB |
| VLarge | 8 GB |

For large amounts of log files, consider increasing the RAM disk size to accommodate the additional data.
